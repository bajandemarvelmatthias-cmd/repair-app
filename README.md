# LunasTech: Mobile-Based Device Repair Simulation and Decision Support Application

Backend and structure (Node.js + Express + node:sqlite).

## Run
    npm install
    npm run seed
    npm run dev

Open http://localhost:3000/api/health

Default admin (change in .env): admin@repairapp.local / Admin@12345

## Customer dashboard design
The customer pages use the LunasTech design (public/css/customer.css). Optional photos go in
public/img/ (see public/img/README.txt).
